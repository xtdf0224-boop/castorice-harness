栖枝浏览器

这是 Agent 和你共用的浏览器窗口。开启「浏览器」的工作任务会在这里打开网页、读取内容、点击和输入，你可以随时看着它做，也可以自己接管。

必应cn.bing.com 百度baidu.com GitHubgithub.com 知乎zhihu.com 哔哩哔哩bilibili.com
  • 需要登录的网站，请先在这里自己登录；登录状态只属于这个窗口，和你平时用的浏览器分开。
  • Agent 打开网址、点击和输入，默认先征求你的确认（可在「工具与技能」里调整）；Codex 不能逐项确认，会直接执行。它不会替你输入密码或付款。
  • 为了安全，这里不会打开本机或内网地址，也不能下载文件。在「工具与技能 › 浏览器控制」里可以一键清除浏览数据。
